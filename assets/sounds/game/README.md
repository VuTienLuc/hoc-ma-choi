# Âm thanh Học mà chơi

Đưa tệp MP3 vào thư mục này theo tên:

- `nhac-nen.mp3` – nhạc nền lặp lại.
- `bat-dau.mp3` – bắt đầu trận.
- `chon-dap-an.mp3` – khi chọn phương án.
- `dung.mp3` – trả lời đúng.
- `sai.mp3` – trả lời sai.
- `dem-nguoc.mp3` – những giây cuối.
- `chien-thang.mp3` – màn hình kết quả.

Khuyến nghị: mỗi hiệu ứng khoảng 30–100 KB; nhạc nền nên ngắn và nén nhẹ.
